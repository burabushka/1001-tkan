# 1001 Ткань — Design MD

## Приоритет источников

1. `brandbook.html` — источник истины для бренда, цветов, шрифтов, радиусов и визуального тона.
2. `main-page-design.html` + `web_design.css` — источник для структуры главной, карточек, каталожной логики и поведения UI.
3. Контекст чата — B2B-лендинг: «От метража до тиража», опт, рулоны, образцы, логистика, FAQ, калькулятор.
4. Furniture Website Figma — только композиционный референс: крупные rounded-плашки, hero-ритм, плотные карточки. Цвета Furniture не главные.

## Короткий промт

Создать B2B-лендинг «1001 Ткань» для оптовых покупателей, ателье, мастеров и производств.

Дизайн строить по брендбуку: белая основа, цвета логотипа, теплая editorial-палитра тканей, крупные округлые формы, вертикальные изображения для каталога и ленты, широкие баннеры для промо.

Главная идея: «От метража до тиража» — магазин помогает подобрать ткань, проверить образец, купить рулон со скидкой и быстро получить отгрузку с документами.

## Палитра

Брендбук выше всех других референсов. Цвета восстановлены по номерам из палитры.

| Token | Hex | Роль |
|---|---:|---|
| `--brand-red` / Logo Red | `#F00613` | главный CTA, точки-акценты, цена, активное действие |
| `--brand-blue` / Ink Blue | `#2F2F83` | брендовый темный акцент, активные chips, B2B-блоки |
| `--ink` / Graphite | `#262626` | основной текст, темные кнопки, footer |
| `--paper` / White | `#FFFFFF` | основной фон и карточки |
| `--page-bg` | `#F2EFEC` | теплый внешний фон/board background |
| `--soft-rose` | `#F8EDED` | мягкий hero/banner фон |
| `--linen` | `#EEE2D3` | нейтральная тканевая подложка |
| `--sand` / Warm Sand | `#D9BA8E` | теплые промо-акценты, premium-зоны |
| `--sea` / Sea Blue | `#A8CFDA` | холодный спокойный акцент для категорий |
| `--petal` / Petal Pink | `#F4B6C7` | fashion/editorial акцент |
| `--velvet` / Velvet Green | `#063D2E` | глубокий premium/dark accent |
| `--surface` / Warm Surface | `#FAF8F6` | карточки, chips, FAQ, формы |
| `--border` / Border | `#EBE7E4` | тонкие границы и разделители |

Запрещено делать основную палитру из `#F2D784`, `#4F4A67`, `#F16151`: это цвета Furniture-референса, не бренда 1001 Ткань.

## Типографика

| Роль | Шрифт | Вес | Использование |
|---|---|---:|---|
| Display | `Literata`, Georgia, serif | 600-700 | H1, H2, editorial-заголовки, крупные цифры |
| Body/UI | `Inter`, Arial, sans-serif | 400-800 | навигация, карточки, формы, кнопки, FAQ, цена |

Правила:
- `letter-spacing: 0`;
- H1 крупный, спокойный, editorial: 56-72px desktop, 40-48px mobile;
- body 16px для лендинга, 14px для карточек/служебных подписей;
- цены и B2B-цифры можно делать Inter 800 или Literata 700.

## Формы и компоненты

Радиусы из брендбука:
- small controls: `12px`;
- buttons / inputs: `18px`;
- cards: `28px`;
- banners: `38px`;
- pills/chips: `999px`.

Компоненты:
- Header: sticky, белый `#FFFFFF` с blur, border `#EBE7E4`.
- CTA primary: `#F00613`, белый текст.
- CTA secondary: белый фон, border `#EBE7E4`, текст `#262626`.
- Active chip/tab: `#2F2F83`, белый текст.
- Card: `#FFFFFF` или `#FAF8F6`, border `#EBE7E4`, radius 28px.
- B2B-dark block: `#2F2F83` или `#262626`; красный использовать точечно.
- Form fields: белая поверхность, тонкая граница, крупный radius, понятные labels.
- FAQ: accordion-карточки на `#FAF8F6`, active marker `#F00613`.

## Изображения

Брендбук:
- каталог и товарные карточки: вертикальные фото `3 / 4`;
- лента/post: вертикальные фото `9 / 16`;
- промо/banner/hero: широкий формат `16 / 7`;
- все изображения без встроенного текста; текст, кнопки и CTA — только HTML/UI;
- радиус изображений: 24-28px, баннеры до 38px.

Для wireframe-прототипа фото заменять серыми плейсхолдерами, но сохранять реальные пропорции.

## Главная страница

Обязательная структура:

1. Header  
   Лого «1001 Ткань», навигация, телефон, CTA «Заказать звонок».

2. Hero  
   H1: «От метража до тиража.»  
   Подзаголовок: «Заказывайте ткани оптом для мастеров и производств.»  
   CTA: «Подобрать» и «Каталог».  
   Под CTA — 3 горизонтальных буллита:
   - `5.000+ рулонов`;
   - `Образцы за 3 дня`;
   - `Скидка 37% от 1 рулона`.

3. B2B-блок  
   Тестовый метраж → подбор → образец/видео → целый рулон со скидкой 37%.

4. Доверие и масштаб  
   28 лет, физическое наличие в РФ, отгрузка 24 часа, 4 магазина.

5. Стандарты качества  
   Цвета без сюрпризов, PANTONE-ориентир, повторяемость партии.

6. B2B сервис  
   Персональный менеджер, воспроизводство от 50 м, документы, ТК.

7. Калькулятор / форма  
   Классическая форма + AI-помощник. Минимум полей: тип изделия, ткань, объем, город/срок.

8. FAQ и корзина  
   Статус оптовика, образцы, повтор партии, оформление по безналу.

9. Footer  
   О компании, сервис, реквизиты.

## UX-акценты

- Главная страница должна продавать не «красивую ткань», а управляемую закупку: наличие, образец, рулон, документы, доставка.
- B2B и розницу не смешивать в одном оффере: B2B — рулон/партия, розница — первый заказ от 5 000 ₽.
- В корзине показывать прогресс до условия скидки и релевантные дополнения: подклад, молнии, фурнитура.
- Менеджер отвечает до 10 минут в рабочее время: это можно вынести в форму/AI-блок.
- Все ключевые действия должны вести к заявке или каталогу, не к декоративным секциям.

## Что поправить в текущем HTML-прототипе

- Заменить Furniture-палитру:
  - `coral` → `brandRed #F00613`;
  - `violet` → `brandBlue #2F2F83`;
  - `gold` → не основной цвет; заменить на `softRose`, `linen`, `sand` по смыслу.
- Вернуть display-шрифт к `Literata` вместо Urbanist.
- Hero сделать теплее: `linear-gradient(105deg, #F8EDED, #FFFFFF 62%)`.
- Фото/плейсхолдеры держать в брендовых пропорциях: hero/banner `16/7`, карточки `3/4`.
- Сохранить текущую B2B-структуру из чата, но визуально привести ее к брендбуку.
